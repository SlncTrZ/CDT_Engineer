# Mechanical Reconstruction — Benchmark Pack

> Documentation class: PUBLIC_DOMAIN
> Version: 0.3.0 · Status: frozen CDT-SolidWorks parallel contract mapped; final composition/runtime acceptance pending.

## Baseline
The inspected 2026-09-11 mechanical appendix remains historical partial evidence: staged ACIS operations and Boolean receipts do not establish SolidWorks-native editability, topology identity, dimension correctness or manufacturing readiness. Exact source fixture/hash, source-linked dimensions and tolerances must be frozen from private evidence before replay. Do not manufacture a golden model or treat sampled geometry as an independent oracle.

## Current runtime gate
CDT-SolidWorks now has a source-mapped public contract, including Agent-5 reconstruction routes, but source mapping is **not runtime proof**. Before MP-03 or later mutation, runtime discovery must verify the final Agent-7-composed provider/build, required live tool names, capability availability, SolidWorks dependency/license readiness and the injected reconstruction ports.

Typed blockers include `parallel_integration_not_accepted`, `provider_unreachable`, `tool_missing`, `capability_missing`, `dependency_unavailable`, `license_unverified`, `runtime_unknown`, `reconstruction_port_binding_pending` and `exact_transaction_mode_unproven`. Direct COM/.NET bypass is not CDT_Engineer production evidence.

## Cases
- **MP-01 — interpretation:** reconcile orthographic views, dimensions, units, datum/frame assumptions and ambiguity; independent interpretation review required.
- **MP-02 — reconstruction plan:** validate the feature DAG, analytic primitive evidence, critical-dimension ledger and intended edit against frozen requirements. Select direct edit / recognition / parametric rebuild / approximation / refuse without pretending to recover original feature history.
- **MP-03A — controlled neutral CAD:** `reconstruction_assess` a STEP/IGES/Parasolid source, then for an accepted controlled bracket or turned/shaft case use `reconstruction_step_to_editable`. Require ordinary editable features, explicit source hash, units/frame confidence and critical-dimension tolerance. Any unavailable topology/part port is BLOCKED.
- **MP-03B — controlled mesh:** `reconstruction_assess` the STL, require watertight/manifold evidence plus primitive-fit confidence/residuals, then use `reconstruction_mesh_to_parametric` only when the declared approximation tolerance is satisfied. Ambiguous fit must be refused.
- **MP-04 — independent verification:** use released query/measurement routes such as `evaluation_measure`, feature/body queries and `reconstruction_compare` to independently verify holes, radii/diameters, depths, placements, body count and critical dimensions. A generic bbox/volume/screenshot is insufficient.
- **MP-05 — persistence/exchange:** save with the released document lifecycle route, reopen the native artifact, repeat critical measurements, then export the required supported neutral 3D format and reopen with an identified reader. Compare units, topology and critical dimensions; record real deviation rather than assuming zero.
- **MP-06 — recovery:** inject early/middle/late/uncertain failures only through the released provider and verify the provider's actual recovery behavior. Do not label it atomic until runtime evidence supports that class.

## Controlled fixtures
Initial editable-reconstruction acceptance is intentionally bounded to two families:

1. **Prismatic bracket:** planar base/boss/cut construction with explicit width/height/depth and one or more provable cylindrical holes where source evidence supports them.
2. **Turned/shaft part:** axial/revolved ordinary features with explicit overall length and outer diameter plus only source-proven steps/bores/grooves.

These cases validate the orchestration contract. They do not imply arbitrary STEP feature-history recovery or generic STL reverse engineering.

## Reconstruction evidence contract
For each source record:

- source path/identity and SHA-256;
- source class: neutral CAD, native imported body, mesh, or degraded/mixed refusal;
- unit and coordinate-frame confidence;
- body/topology or mesh statistics;
- analytic primitive/feature evidence only when provable, including confidence and fit residual where applicable;
- missing design semantics such as original feature history, constraints, tolerances and feature intent;
- selected strategy and explicit refusal reason when evidence is insufficient.

For each rebuilt output record feature identities, reopen verification and a critical-dimension ledger containing expected value, actual measured value, tolerance and absolute deviation. If an intended parametric edit is part of the case, it must be applied after reopen and read back successfully.

## Failure / recovery matrix
MP-06 must include:

- **early failure:** provider/runtime discovery, invalid source class, ambiguous projection/primitive fit, missing topology/mesh/part port, unsupported benchmark class or missing critical dimensions blocks before mutation;
- **middle failure:** force feature/Boolean/rebuild failure after dispatch, inspect feature/body/document state, and prove no duplicate/corrupt mutation before retry;
- **late failure:** fail critical-dimension verification, save/reopen, drawing handoff or neutral export/reopen after native mutation; release evidence is invalid until independently reconciled;
- **uncertain completion / timeout:** query current feature/body/document state before any retry; never blindly repeat a non-idempotent feature or reconstruction mutation.

`checkpointed_atomic` is accepted only after runtime proof that a saved checkpoint restores and independently verifies the full pre-chunk native state under injected failure. Otherwise record the weaker behavior actually observed.

## Negative and scale ladder
Require negative cases for unsupported source extension, missing source file, unit/frame uncertainty, mixed/degraded representation, non-watertight/non-manifold mesh, low primitive confidence, fit residual over tolerance, recognized-class mismatch, dimension-set mismatch, missing runtime tool/capability and unavailable injected ports. Scale performance budgets only after native correctness is established on the final composed provider/runtime.

## Oracle and release
A responsible reviewer freezes source-linked dimensions, tolerances, expected topology and required exchange format before generation. Exact reconstruction cannot pass using unapproved sampled radii or inferred dimensions with no provenance. `reconstruction_compare` is a deterministic comparator, not a measurement oracle.

Record exact native application, CDT-SolidWorks provider/build/public contract, final tool discovery, pack versions, tool receipts, independent inspector/measurement source, output hashes and unresolved findings. Required provider capability or export unavailable means BLOCKED, not native-only PASS. Final release requires both native and required neutral artifacts to satisfy the domain review rubric; content-addressed `artifact.seal` remains separately unproven until a released route exists.

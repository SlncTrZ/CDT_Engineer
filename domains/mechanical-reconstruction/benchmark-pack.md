## Failure / recovery matrix

Once the required public routes exist, MP-06 must include:

- **early failure:** provider/runtime preflight, invalid feature prerequisites, cyclic dependency or unsupported required capability blocks before native mutation;
- **middle failure:** force feature/Boolean mutation failure, reconcile feature-tree/body state, restore/compensate according to the proven recovery mode and verify no duplicate feature before retry;
- **late failure:** checkpoint/save/reopen, independent measurement or neutral export/reopen failure invalidates dependent release evidence;
- **uncertain completion / timeout:** query the current feature/body/document state before any retry; never blindly repeat a non-idempotent feature operation.

No recovery class is accepted from source prose alone. Checkpoint restoration must independently prove the complete pre-chunk native state where `checkpointed_atomic` is claimed.
